# 트리 꾸미기
포도 키우기의 출석·보상 구조를 재사용하는 트리 꾸미기 게임 기획 저장소.

## 확정된 방향
- 상단 트리 슬롯 5개 중 선택한 트리 한 개만 중앙에 표시.
- 첫 트리는 초록색 고정, 추가 네 트리는 생성 시 랜덤 색상.
- 0일차에는 큰 트리만 존재하고 출석마다 장식 한 개 추가.
- 마지막 출석에 꼭대기 별 한 개를 달아 완성.
- 기존 포도 키우기의 출석·광고·보상 조건 유지.

**트리와 오너먼트 디자인은 미확정입니다.** 배경·받침·UI 이미지 역시 콘셉트 참고용입니다. 초기 시안의 5개 동시 전시 구도는 폐기되었으며 실제 구조는 상단 슬롯 5개와 중앙 트리 1개입니다.

랜덤 색상의 후보·확률·중복 허용은 기획서의 초기 기본안이며 최종 에셋 확정과 구분합니다. 현재 저장소에는 기획과 시안만 있으며 게임 구현은 포함하지 않습니다.
