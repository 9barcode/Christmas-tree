# 홈·이용안내·보상 내역 시안 반영

- 상단 크림색 제목과 작은 잎 장식, 금색 테두리 슬롯, 실제 자물쇠 모양을 적용한다.
- 트리와 화분의 현재 배치와 트리 크기를 유지하고, 보조 메뉴 세 개를 트리 아래 가로줄로 배치한다.
- 초록 출석 버튼과 얇은 크림색 출석 미션 카드를 적용한다. 확정한 버튼 문구와 상태 전환은 유지한다.
- 안내는 둥근 크림색 종이 패널과 항목 사이 구분선으로 구성한다. 출석/결석 문구 및 장식 터치 배치 안내는 유지한다.
- 보상 내역은 6열 30칸이며 동일한 루돌프 그림에 붉은 출석 표시를 찍는다. 빈칸은 점선 원, 마지막 칸은 별로 표시한다. 실제 포인트 계산/지급 로직은 바꾸지 않는다.
- 새 벡터 에셋: assets/ui/book.svg, gift.svg, calendar.svg, holly.svg (프로젝트를 위해 직접 작성). 기존 배경·트리·화분·루돌프·별 그림 재사용.
- 글꼴: Jua(주아체), Copyright 2018 The Jua Project Authors, SIL OFL 1.1. 공식 원본 https://github.com/google/fonts/tree/main/ofl/jua. 앱·게임에 포함 가능하며 라이선스와 저작권 문구를 assets/fonts/OFL-Jua.txt에 포함한다. 현재 UI 문자와 ASCII를 포함한 WOFF 서브셋을 로컬 제공한다. 새로운 한국어 문구 추가 시 서브셋 갱신이 필요하며, 누락 문자는 시스템 sans-serif로 대체된다.
- 서버·DB 및 광고/보상 SDK 연결은 이번 범위에 포함하지 않는다.
