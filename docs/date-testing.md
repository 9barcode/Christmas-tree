# 임시 날짜 테스트

홈 아래 `임시 날짜 테스트`를 누르거나 `/?preview=1`로 진입한다. 실제 저장 진행도 대신 메모리의 새 테스트 진행도를 사용하며 새로고침하면 초기화된다. 실제 광고, 서버, DB, 포인트 지급은 호출하지 않는다.

1. 출석 버튼으로 장식을 받고 배치한다. 같은 날 같은 트리는 두 번 출석할 수 없다.
2. `다음 날 +1일`을 누르고 다시 출석한다. 모든 슬롯에 같은 테스트 날짜가 적용된다.
3. 출석 후 다음 날 버튼을 두 번 눌러 하루 건너뛰면 꾸미기가 마무리되고 선물 받기 버튼으로 바뀐다.
4. 테스트 화면에서 선물 받기를 누르면 지급 완료 화면을 모의 표시한다. 실제 지급은 없다.
5. 30일 연속 출석 후 테스트 수령하면 자랑하기/상단 슬롯 다시 시작을 확인할 수 있다.
6. `처음부터`로 테스트를 초기화하거나 `테스트 종료`로 원래 진행도로 돌아온다.

기기 날짜는 바꾸지 않는다. 임시 기능 제거 시 home.js의 testTools 블록과 preview 시계 연결, test-clock.js, 관련 CSS와 테스트를 함께 정리한다.
