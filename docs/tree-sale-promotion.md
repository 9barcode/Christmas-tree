# 완성 트리 판매 50P 지급

- Worker Secret `TOSS_PROMOTION_CODE_TREE_SALE`: 완성 트리 판매 전용 50P 프로모션.
- `TOSS_PROMOTION_CODE_EXCHANGE`: 보유 벨의 토스포인트 교환 전용. 트리 판매와 별개다.
- 트리 판매는 기존 전면광고 완료 후 고정 50P를 직접 지급한다. 벨은 적립하거나 차감하지 않는다.
- 도감 30종 및 서로 다른 장식 30개 배치 조건, 사용자당 1회 판매 조건을 유지한다.
- 기존 50벨 판매 기록이 있는 계정은 추가로 50P를 받지 않는다. 기존 벨 잔액도 변경하지 않는다.
- 지급 대기 중 장식을 판매 상태로 예약하며, 같은 지급 키로 결과를 조회한다. 대기 건은 트리 화면의 지급 결과 확인 버튼과 재접속 시 복구한다.
- 지급 실패 확정 시 예약한 장식을 보관함에 미배치 상태로 돌려준다. 다시 배치하고 판매를 재시도할 수 있다.
- 디버그 ON은 기존 허용 계정에서만 테스트 코드를 사용한다. `TOSS_PROMOTION_MODE=test`도 테스트 코드를 사용하며 실제 포인트는 지급하지 않는다.

## 적용

1. treemoa Worker에 `TOSS_PROMOTION_CODE_TREE_SALE`을 등록하고 토스 콘솔의 50P 설정을 맞춘다.
2. D1에 `0009_tree_sale_promotion.sql`까지 적용한다.
3. Worker 배포 후 AIT를 재빌드한다.

프로모션 홈 노출 등록은 토스 콘솔 설정이며, 이 변경은 앱의 트리 판매 버튼과 서버 지급 경로를 연결한다.
