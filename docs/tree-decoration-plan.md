# 트리 꾸미기 기획서 v0.2

작성일: 2026-10-15
상태: 게임 규칙 기획 및 미확정 비주얼 콘셉트. 포도 키우기 구조를 재사용하는 에셋 교체형 게임.

> 트리·오너먼트·배경·받침·UI 이미지의 구체적인 디자인은 모두 미확정이다. 첨부 이미지는 배치와 분위기 참고용이며 실제 게임용 확정 에셋이 아니다. 확정된 것은 게임 진행 규칙과 상단 5개 슬롯/중앙 1개 보기 구조, 첫 트리 초록 및 추가 트리 랜덤 색상 규칙이다.

## 1. 핵심 콘셉트
매일 출석하여 크리스마스트리에 오너먼트를 하나씩 달고, 마지막 출석에 꼭대기 별을 달아 트리를 완성한다. 최대 5개의 트리를 보유하며, 상단의 트리 슬롯 5개 중 하나를 선택해 해당 트리만 중앙에 크게 표시한다.

0일차부터 완성 크기의 큰 초록색 트리 한 개가 있다. 첫 트리는 초록색으로 고정하며 추가 트리 네 개는 생성 시 색상을 무작위로 정한다. 출석으로 트리 크기나 가지 수가 커지는 것이 아니라 장식이 누적된다. 완성한 트리와 장식은 계속 남는다.

## 2. 포도 키우기와의 대응

| 포도 키우기 | 트리 꾸미기 |
|---|---|
| 기본 포도 식물 | 장식 없는 큰 트리 |
| 출석으로 포도알 추가 | 출석으로 오너먼트 하나 추가 |
| 마지막 성장 단계 | 꼭대기 별 부착 및 완성 |
| 상단의 화분 슬롯 5개와 개별 보기 | 상단의 트리 슬롯 5개와 개별 보기 |
| 출석 팝업·누적 출석 | 같은 위치·구조·동작 유지 |
| 미션·프로모션 보상 | 같은 조건·수치·지급 구조 유지 |
| 포도 관련 이미지·문구 | 트리·장식 이미지와 대응 문구로 교체 |

화면 배치, 버튼, 출석 처리, 광고 노출, 보상 조건, 다음 개체 생성 조건, 저장 방식은 원본을 기준으로 유지한다. 신규 재화·랜덤 뽑기·추가 광고 조건은 넣지 않는다.

이 초안은 저장소를 확인한 구현 명세가 아니다. 원본의 전체 출석 단계 수·보상 수치·5개 생성 조건은 구현 착수 시 현재 설정을 확인하여 그대로 복사한다. 이전에 제작한 1~18알 이미지를 전체 출석 기간으로 단정하지 않는다.

## 3. 출석과 장식 규칙
원본의 완성 필요 출석 횟수를 N이라고 한다.

| 단계 | 화면 상태 | 이번 출석으로 추가되는 것 |
|---|---|---|
| 0일차 | 큰 트리 1개와 받침만 표시 | 없음 |
| 1일차 | 가지에 첫 장식 1개 | 오너먼트 1개 |
| 2~N-1일차 | 앞서 단 장식을 유지하며 누적 | 매 출석 오너먼트 1개 |
| N일차 | 꼭대기 별이 달린 완성 트리 | 별 1개 |

완성 시 장식 총 N개는 일반 오너먼트 N-1개와 꼭대기 별 1개로 구성한다. 마지막 날에도 추가 장식은 정확히 한 개다. 별은 이전 단계에 미리 표시하지 않는다.

출석 완료 후 ‘오늘의 장식 달기’를 누르면 미리 정한 위치에 자동 부착한다. 이 동작은 원본의 성장 연출 버튼 흐름에 맞춘다. 자유 드래그 배치나 장식 선택 기능은 이번 버전에 넣지 않는다.

하루 중복 수령, 출석 초기화 기준, 결석 시 처리, 누적·연속 출석 판정은 원본과 동일하다. 결석만으로 장식을 없애는 새로운 규칙은 추가하지 않는다.

## 4. 장식 종류와 배치
일반 장식은 빨강·금색·아이보리 구슬, 리본, 종, 사탕 지팡이, 눈송이 등으로 구성한다. 순서와 위치는 고정해 매일 다른 장식이 추가되는 모습이 분명하게 보이도록 한다.

초기에는 눈에 잘 띄는 중앙 가지에 배치하고 이후 좌우와 위아래를 번갈아 채운다. 장식끼리 심하게 겹치거나 트리 바깥에 뜨지 않도록 슬롯을 정한다. 별 전용 슬롯은 꼭대기 중앙 한 곳이다. 구슬·종·눈송이에 작은 얼굴을 넣어 포도 게임의 친근한 분위기를 이어갈 수 있다.

전구나 긴 가랜드를 별도 장식으로 사용한다면 하나의 출석 단계에 한 에셋만 추가한다. 자동으로 여러 소품이 함께 생기는 연출은 피한다.

## 5. 상단 트리 슬롯 5개와 개별 보기
포도 키우기처럼 화면 상단에 트리 슬롯 5개를 둔다. 슬롯을 누르면 선택한 트리 한 개만 중앙에 크게 표시한다. 다섯 트리를 한 화면에 나란히 배치하거나 앞뒤로 전시하지 않는다.

각 슬롯은 해당 트리의 작은 아이콘과 진행·완료 상태를 보여주며, 선택한 슬롯은 테두리 등으로 구분한다. 아직 생성하지 않은 슬롯은 원본 화분 슬롯과 동일한 방식으로 표시한다. 완성한 트리도 슬롯에 남아 다시 선택해 볼 수 있다.

최대 수량, 추가 생성 시점, 출석 적용 대상과 범위는 원본과 동일하게 유지한다. 트리가 여러 개라는 이유로 하루 장식 지급 횟수를 새로 늘리지 않는다. 트리마다 진행도, 붙은 장식, 완료 여부를 개별 보관하며 슬롯을 전환해도 서로 섞이지 않는다.

중앙 트리의 표시 영역과 크기는 슬롯 수에 따라 축소하지 않는다. 장식은 선택한 트리의 진행도에 맞춰 표시한다.

### 트리 색상 규칙
- 첫 번째 트리는 초록색으로 고정한다.
- 두 번째~다섯 번째 트리는 생성 시 색상을 무작위로 한 번 결정한다.
- 기본 색상 후보는 초록·화이트(설원)·핑크·민트다. 시안처럼 같은 형태의 트리에 색상 변화를 준다.
- 구현 기본안은 네 색상 동일 확률이며 중복을 허용한다. 추가 트리에서도 초록색이 나올 수 있다. 이는 초기 제안값이며 사용자 확정 사항과 구분한다.
- 결정한 색상을 트리별로 저장한다. 슬롯 전환·출석·재접속·완성 시 다시 추첨하지 않는다.
- 상단 슬롯 썸네일은 실제 트리의 색상과 장식 진행도를 반영한다. 미완성 썸네일에 별을 미리 표시하지 않는다.
- 색상은 외형에만 영향을 준다. 출석 필요 횟수·보상·장식 지급·완성 조건은 동일하다.
- 모든 색상의 트리는 생성 시 장식이 없으며 마지막 출석에만 별을 단다.
- 색상별 트리 에셋은 형태·크기·장식 부착 좌표를 통일한다.
- 색상 식별자(treeColor)는 트리 생성 데이터와 함께 저장한다. 생성 재시도로 기존 색상이 바뀌지 않게 한다.

## 6. 화면과 문구
- 메인: ‘트리 꾸미기’, 누적 출석, 현재 진행도, 상단 트리 슬롯 5개와 선택 트리 표시 영역, 기존 출석·미션 버튼.
- 출석 완료: ‘오늘도 반가워요!’와 당일 장식 이미지, ‘장식 달기’ 버튼.
- 장식 부착 후: ‘오늘의 장식을 달았어요!’라는 짧은 피드백.
- 완성: ‘반짝이는 트리 완성!’과 별 부착 연출, 원본과 같은 보상 확인 흐름.
- 미션: 기존 x일 달성·보상 금액과 지급 동작 유지. 관련 아이콘만 트리 소품으로 변경.

원본의 주아체와 둥근 버튼·팝업 분위기를 유지한다. 출석 팝업 아래의 중복 ‘몇 일차 출석 완료’ 문구는 넣지 않는다. 새 게임의 운영 상태와 무관한 지급 테스트 안내 문구를 임의로 추가하지 않는다.

## 7. 시각 방향
부드러운 2D 캐주얼 일러스트. 짙은 초록 트리, 빨강·금색 장식, 크림색 UI와 따뜻한 목재 받침을 사용한다. 배경은 눈 내리는 창문이 있는 아늑한 실내를 제안한다. 기존 배경을 이 테마로 교체하되 버튼과 주요 정보의 위치는 유지한다.

0일차는 이미 큰 트리가 보이는 구도다. 진행 중에는 장식 누적이 명확히 보이고, 완성 시에만 꼭대기에 별이 등장한다. 시안은 시각 방향 제안이며 실제 원본 화면을 픽셀 단위로 복제한 결과가 아니다.

## 8. 에셋 분리 명세
| 에셋 | 역할 | 제작 기준 |
|---|---|---|
| 실내 배경 | 공통 배경 1장 | 트리·받침·UI를 포함하지 않음 |
| 기본 트리 | 초록·화이트·핑크·민트 색상별 원본 | 형태·크기·부착 좌표 통일, 장식·별·받침 없는 투명 배경 |
| 받침·화분 | 각 트리 아래 배치 | 트리와 분리된 투명 이미지 |
| 일반 장식 | 일차별로 한 개 부착 | 종류별 독립 투명 이미지, 필요 시 재사용 |
| 꼭대기 별 | 마지막 날 전용 | 투명 배경, 중심 정렬 |
| 반짝임 | 장식·완성 피드백 | 게임 오브젝트와 분리 |
| UI 아이콘 | 출석·미션·완성 | 기존 아이콘 크기와 비율 유지 |

기본 트리는 예시로 1024px급 원본, 장식은 256px급 원본으로 제작하고 최종 크기는 원본 렌더링 크기에 맞춘다. 같은 에셋을 5개 트리의 개별 보기에서 재사용한다. 트리와 부착 장식은 같은 부모 좌표계에 묶어 함께 축소한다. 슬롯은 트리 기준 정규화 좌표로 저장해 크기가 달라져도 위치가 어긋나지 않게 한다.

완성 단계마다 통이미지를 새로 생성하지 않는다. 배경 → 선택한 트리 그룹 1개 → UI 순서로 그리고, 트리 그룹 내부에서는 받침 → 트리 → 일반 장식 → 별 → 효과 순서를 사용한다.

## 9. 데이터와 구현 범위
출석 기록, 보상 처리, 광고, 로그인, 저장 구조는 원본을 재사용한다. 기존 성장 단계 값으로 표시할 장식 수를 결정하고 트리별 장식 슬롯 목록을 테마 설정으로 관리한다. 별도 장식 인벤토리 시스템은 만들지 않는다.

포도 게임과 별도 앱으로 운영할 경우 사용자 진행도·보상 기록이 섞이지 않도록 앱 식별과 데이터 구분은 필요하다. 포도 게임에서 쌓은 출석을 자동 이전하는 기능은 이번 범위에 포함하지 않는다.

## 10. 확인 기준
- 신규 시작 시 장식과 별이 없는 큰 초록색 트리 한 개가 보인다.
- 2~5번째 트리는 생성 시 색상이 추첨되며 재접속·출석·슬롯 전환 후에도 유지된다.
- 상단 슬롯과 중앙 트리의 색상·진행도가 일치한다.
- 출석 한 번당 정확히 장식 하나가 추가된다.
- 재접속 후 장식 위치와 진행도가 유지된다.
- 마지막 출석에서만 별이 꼭대기에 붙는다.
- 완성까지 필요한 출석 수와 보상은 원본과 일치한다.
- 상단 슬롯 5개를 전환하면 선택한 트리 한 개만 중앙에 표시되며, 각 트리의 장식·별·진행도가 정확히 유지된다.
- 6번째 트리는 생성되지 않는다.
- 출석·광고·프로모션 지급 흐름은 에셋 교체 전과 동일하게 동작한다.

## 11. 제작 순서
1. 현재 포도 키우기 설정과 화면을 기준으로 단계 수·보상·생성 조건 확정.
2. 기본 트리, 받침, 장식, 별, 배경을 각각 제작.
3. 일차별 장식 종류와 부착 좌표 설정.
4. 기존 화면에 테마와 대응 문구 적용.
5. 0일차·진행 중·완성·상단 5개 슬롯 전환 및 기존 지급 흐름 확인.

게임명은 임시로 ‘트리 꾸미기’를 사용한다. 신규 기능 없이 포도 키우기의 구조를 그대로 적용하는 것이 이번 버전의 기준이다.

## 시안 정정
초기 이미지의 네 번째 화면에 있는 트리 5개 동시 전시는 적용하지 않는다. 최종 UI는 상단에 작은 트리 슬롯 5개, 중앙에는 선택한 트리 한 개를 크게 표시하는 구조다.

## v0.2 업데이트
