# 프론트 표시 캐시

- 이미지·SVG·폰트만 Cache Storage에 저장. API, 계정 정보, 광고 응답, 보상·판매·프로모션 응답은 대상에서 제외한다.
- 빌드 시 파일 내용의 해시로 캐시 버전을 생성한다. 다음 버전 활성화 시 이 앱의 이전 이미지 캐시만 삭제한다.
- 방문한 이미지부터 저장하며 전체 에셋을 선다운로드하지 않는다. 홈 준비 후 이미 요청한 에셋 중 최대 12개만 백그라운드로 보충한다.
- 디스크 캐시는 최대 32MiB·48개, 파일당 최대 4MiB. 용량 부족·비공개 모드·Service Worker 미지원 시 일반 로딩으로 동작한다. 캐시는 기기에서 정리될 수 있다.
- 사진 내보내기의 디코딩된 이미지 재사용은 최대 32MiB·12개. 화면을 떠나면 메모리를 비운다.
- 사진 저장·공유 창을 다시 열면 동일 배치·동일 화면 크기의 준비된 사진 1개를 재사용한다. 배치 변경·크기 변경 시 재생성하며 화면을 떠나면 비운다.
- 배치가 동일한 트리는 DOM을 재생성하지 않는다. 서버 상태 로딩·소유권·광고 완료·판매 한도 검증은 기존대로 유지한다.
- 계정 상태를 디스크에서 복원하지 않는다. 공용 그림만 저장하므로 사용자 변경 시 다른 사용자의 보관함이나 잔액이 보이지 않는다.
- `npm run build` / AIT 빌드는 생성된 `asset-cache-worker.js`를 포함한다. 앱에서 실제 지속 캐시 지원 여부는 실행 환경에 따라 다르며, 화면 준비는 등록 성공을 기다리지 않는다.

이미지의 픽셀, 비율, 투명도, PNG 원본은 변경하지 않는다. 이미지 경량화는 별도 작업이다.
