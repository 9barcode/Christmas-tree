# 완성 트리 공유 및 슬롯 다시 시작

- 제목 아래 기존 상단 슬롯 위치를 유지한다.
- 30회 완성과 보상 수령이 모두 확인되면 메인 버튼은 `내 트리 자랑하기`가 된다. 출석 미션 카드와 장식 배치 링크는 숨긴다.
- 보상을 받은 슬롯에는 ↻ 표시가 생긴다. 현재 선택된 슬롯을 누르면 바로 아래 작은 메뉴로 `새 트리 꾸미기`가 열린다. 다른 슬롯은 첫 터치로 선택하고 다시 터치하면 메뉴를 연다.
- 공유 팝업은 `사진으로 저장하기`, `친구에게 보내기`를 제공한다. 배경과 실제 장식 위치를 PNG로 합성하고 `30일 동안 정성껏 꾸민 나의 트리` 문구를 넣는다. 버튼·슬롯·포인트는 포함하지 않는다. 추가 광고는 없다.
- 파일 공유 미지원 환경은 PNG 다운로드로 대체한다. 기기별 다운로드/사진 보관 방식은 브라우저·WebView에 따른다.
- 새 트리 시작 전 확인 팝업을 띄운다. 완성 트리는 사진 저장 후 시작하거나 바로 시작할 수 있다. 저장 후 시작은 PNG 다운로드 요청 후 초기화하며 사진 앱 저장 완료를 보장하는 기능은 아니다.
- 중간에 마무리한 트리는 보상 수령 후 메인 버튼에 `새 트리 꾸미기`를 표시한다.
- 초기화는 해당 슬롯의 출석·장식 위치·지급 기록만 지우고 색상과 이미 열린 슬롯을 유지한다. 출석표도 해당 슬롯의 새 회차로 교체한다.
- 회차 `cycle`을 증가시키고 지급 키에도 포함해 이전 수령 기록이 새 트리에 적용되지 않도록 한다. 프론트엔드 지급 어댑터의 prepare/claim/getStatus에도 cycle을 전달한다. 서버/DB는 변경하지 않았다. 서버 담당자는 회차별 지급 식별을 연동해야 한다.

검증: 상태 테스트(공유 조건, 미수령 초기화 차단, 슬롯 유지, 재시작 후 저장 복원, 회차 구분) 포함 `npm test`. 실기기 공유/다운로드 및 시각 검증은 별도로 필요하다.
