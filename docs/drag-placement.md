# 직접 드래그 배치 (최신 규칙)

- 트리, 화분, 획득한 선물/미니카/인형/오너먼트를 직접 잡아서 이동한다. 서로 별개 오브젝트이며 다른 오브젝트와 겹칠 수 있다.
- 별과 전구 줄은 직접 이동할 수 없다. 트리 기준 위치에 고정되어 트리 이동 시 함께 이동한다.
- 바닥 및 가지 내부 제한은 없앤다. 오브젝트 전체가 집 안 꾸미기 영역(상단 UI 아래, 하단 메뉴 위) 안에 남도록 좌표를 제한한다.
- 각 트리 슬롯별 positions에 중심 좌표를 저장한다. 기본 트리/화분은 __tree 및 __pot 키를 쓴다. 과거에 저장된 별/전구 좌표는 무시한다.
- Pointer Events 및 pointer capture를 사용한다. 드래그 중에만 해당 오브젝트에서 스크롤을 차단하고, pointerup에 저장한다. pointercancel/예상치 못한 capture 해제는 시작 위치로 되돌린다. 마우스와 터치를 지원하며 키보드 방향키로도 이동할 수 있다.
- 배치 모드, 위치 선택 팝업, 점선 구역, 배치 완료 버튼, 매번 출석 후 자동 배치 안내를 제거한다. 첫 진입 자동 이용안내도 없애고 사용자가 이용안내를 눌러 볼 수 있게 한다.
- 꾸미기 종료/보상 상태와 출석 규칙은 유지한다. 종료된 트리는 드래그하지 않는다. 다시 시작하면 위치도 초기화된다.
- 신규 에셋 없이 기존 그림을 재사용한다. 서버/DB 변경은 없다.
