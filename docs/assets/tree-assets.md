# 확정 트리 에셋

## 원본과 생성 기준

`docs/images/tree-approved-painterly.png`는 사용자가 최종 승인한 원본이다.
이전 실사풍·단순 색보정·거친 붓터치 시안은 최종 디자인이 아니다.

내장 이미지 생성 도구로 승인 원본을 편집했다. 프롬프트 공통 기준:
원본 실루엣·가지 배치·작은 붓터치·큰 명암을 유지하고, 배경·화분을 제거해 트리 레이어로 분리한다.
잎 색상만 그린·스노우 화이트·블러썸 핑크·아이스 블루·샴페인 골드로 변경한다.
화분은 최신 홈 시안에 맞춘 리본 없는 나무통으로 교체한다. 트리 본체 PNG 5종은 변경하지 않는다.
장식·별·전구·눈·문구는 추가하지 않는다.

## 파일

| 경로 | 내용 |
|---|---|
| `assets/trees/tree-green.png` | 클래식 그린 |
| `assets/trees/tree-white.png` | 스노우 화이트 |
| `assets/trees/tree-pink.png` | 블러썸 핑크 |
| `assets/trees/tree-blue.png` | 아이스 블루 |
| `assets/trees/tree-gold.png` | 샴페인 골드 |
| `assets/planters/planter-wood.png` | 리본 없는 공통 나무 화분 |

각 이미지는 투명 PNG다. 생성형 편집으로 색상별 미세 윤곽 차이가 있을 수 있으므로 오너먼트 부착 좌표는 실제 합성 화면에서 검증한다. 최신 수량 제안은 바닥 소품 6개·트리 오너먼트 23개·별 1개다.
원본 캔버스 내 위치를 보존하도록 생성했으나 화분과 줄기의 결합 위치는 합성 시 확인해야 한다.
배경 → 화분 → 트리 → 일반 장식 → 마지막 별 → 바닥 소품 → UI 순으로 합성한다. 새 화분은 중앙의 독립 오브젝트로 생성되어 기존 화분과 투명 여백이 다르다. 합성 미리보기의 viewBox도 교체한다.

게임 구현과 장식·별 에셋 제작은 이번 변경에 포함하지 않는다.
