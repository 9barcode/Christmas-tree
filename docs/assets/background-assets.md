# 겨울 실내 배경과 모션 v1

- `assets/backgrounds/cozy-europe-room.webp`: 트리·화분·UI 없는 1024×1536 세로 배경.
- `assets/effects/fire-glow.webp`: 투명 불꽃 오버레이. 배경의 작은 기본 불씨 위에서 약하게 크기·투명도를 변화시킨다.
- `assets/backgrounds/cozy-room.css`, `cozy-room.js`: 재사용 가능한 불꽃 및 창밖 눈 모션.
- `previews/cozy-room.html`: 배경과 확정 그린 트리를 합성한 브라우저 확인용 예제. 저장소 루트에서 HTTP로 제공해 확인한다.

내장 이미지 생성으로 제작. 프롬프트: 승인 트리와 같은 겹친 붓터치 색면 표현, 따뜻한 목재·크림 벽·버건디, 좌측 벽난로와 양말, 우측 창문 밖 눈 덮인 유럽 마을, 중앙 트리 배치 공간 확보, 트리 및 UI 미포함.

배경은 정지 이미지이며 모션이 파일 자체에 들어 있지 않다. 불꽃 PNG와 CSS, 창문 유리 영역으로 잘라내는 Canvas 눈을 함께 사용해야 움직인다.
눈은 32개 입자가 천천히 내려오며 창틀·커튼·실내에는 표시하지 않는다. 움직임 줄이기에서는 모션을 끄고 비활성 탭에서는 눈을 중단한다.

트리 합성은 배치 확인용이다. 화면 UI·최종 트리 크기 확정 및 실제 앱 연동은 포함하지 않는다. 배경 비율을 변경하거나 이미지가 잘릴 경우 눈·불꽃도 같은 부모 좌표계에서 함께 변환해야 한다.
