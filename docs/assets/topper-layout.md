# 완성 별: 홈 화면 공간과 시선 우선순위

## 현재 시안 진단

`docs/images/home-cozy-gifts-reference.png`에서 진행도 캡슐 아래쪽과 트리 꼭대기가 거의 맞닿아 있다.
현재 위치에 큰 별을 단순 추가하면 진행도와 겹친다. 작은 별로 타협하지 않고 상단 UI를 압축해 별 전용 공간을 확보한다.
이 문서는 배치 기준이며 실제 홈 UI 수정·실기기 검증 완료를 의미하지 않는다.

## 배치 기준 제안

- 트리·화분 크기는 유지한다. 트리 그룹을 화면 높이의 약 1% 아래로 옮길 수 있으나 출석 버튼과 겹치지 않게 한다.
- 제목·슬롯·진행도 영역을 압축해 진행도 캡슐 하단을 화면 높이의 약 14% 이내에 둔다.
- 별 전용 안전 영역: 화면 가로 44~56%, 세로 15~22.5%. 1024×1536 시안 기준 약 123×115px이다.
- 별은 화면 가로의 약 10~12% 너비, 일반 오너먼트의 약 1.6~2배로 시작해 화면에서 검토한다.
- 별 하단 장착부만 트리 꼭대기와 살짝 겹친다. 별 본체는 녹색 가지 위에 묻히지 않는다.
- 진행도·슬롯·제목과 최소 12~16 디자인 px 여백을 확보한다. 위 수치는 시안 기준이며 실제 터치 화면 px로 혼동하지 않는다.
- 별과 화분이 모두 보이도록 유지한다. 5색 트리에서 별의 윤곽·명암이 분명한지 확인한다.

## 시선 우선순위

1. 마지막 별: 가장 큰 밝은 중심부, 따뜻한 아이보리~금빛, 필요한 경우 부드러운 국소 후광.
2. 트리와 개별 오너먼트: 색과 모양이 읽히지만 별보다 작고 낮은 밝기.
3. 전구 줄: 작은 따뜻한 노란 전구들. 빠른 점멸이나 강한 전면 후광 없이 은은하게.

전구와 별은 별도 에셋이다. 별 후광은 과한 효과가 구워진 배경 대신 런타임 레이어로 조절한다.
샴페인 골드·화이트 트리에서는 별의 진한 금색 가장자리를 보존해 밝은 잎과 구분한다.
0~29회에는 별을 미리 표시하지 않는다. 마지막 30회에 별 한 개가 등장한다.
