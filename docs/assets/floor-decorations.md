# 바닥 소품: 선물·장난감 출석 꾸미기

## 승인한 디자인

[정리한 홈 시안](../images/home-cozy-gifts-reference.png)의 선물 4개 및 리본 없는 나무 화분을 기준으로 한다.
이 시안은 바닥 소품 배치 예시이며, 화면의 0/30 표기와 선물 누적 상태를 동시에 실제 초기 상태로 사용하면 안 된다.
0일차에는 트리·화분만 있으며 바닥 소품은 출석에 따라 누적된다.

## 독립 투명 에셋

| 파일 | 소품 | 상태 |
|---|---|---|
| `assets/planters/planter-wood.webp` | 리본 없는 나무 화분 | 기본 제공, 출석 수 제외 |
| `assets/decorations/gift-burgundy.webp` | 버건디 상자·아이보리 리본 | 출석 소품 1개 |
| `assets/decorations/gift-green-large.webp` | 낮고 넓은 초록 상자·빨간 리본 | 출석 소품 1개 |
| `assets/decorations/gift-cream.webp` | 크림 상자·빨간 리본 | 출석 소품 1개 |
| `assets/decorations/gift-green-small.webp` | 작은 초록 상자·크림 리본 | 출석 소품 1개 |
| `assets/decorations/toy-car.webp` | 빨강·아이보리 나무 미니카 | 출석 소품 1개 |
| `assets/decorations/teddy-bear.webp` | 빨간 목도리 곰 인형 | 출석 소품 1개 |

선물 상자 하나가 한 번의 출석 꾸미기다. 상자 위 리본·작은 잎은 해당 상자 그림의 일부이고 별도 지급 개체가 아니다.
모든 PNG는 개별 중심 배치 에셋이며 트리 PNG와 캔버스를 단순 중첩하지 않는다. 고유 표시 크기와 바닥 기준점을 지정해야 한다.

## 초기 30회 순서 제안

| 출석 회차 | 추가 소품 |
|---|---|
| 3 | 버건디 선물 |
| 7 | 큰 초록 선물 |
| 12 | 미니카 |
| 17 | 크림 선물 |
| 22 | 인형 |
| 27 | 작은 초록 선물 |
| 28 | 트리를 감싸는 전구 줄 전체 1개 |
| 30 | 꼭대기 별 |
| 그 외 22회 | 매 회차 트리 오너먼트 1개 |

수량은 선물 4·미니카 1·인형 1·오너먼트 22·전구 줄 1·별 1로 확정한다. 세부 획득 순서는 아직 제안이다. 총 30회·매 회차 한 개·마지막 별을 유지한다.
선물·장난감 대기 모션은 고정한다. 가지 오너먼트만 일부가 가끔 ±3° 수준으로 움직이며 바닥 소품과 별도 관리한다.

## 제작 프롬프트 기록

내장 이미지 생성 도구로 홈 시안을 참조하여 개별 추출·보완했다.
공통 프롬프트: 지정 오브젝트 하나만 추출, 주변 트리·바닥·UI·다른 상자 제거, 진짜 투명 배경, 오브젝트 전체 표시,
작게 겹친 붓터치 색면·따뜻한 좌측 불빛·큰 명암·원래 비율 유지, 실사·매끈한 3D·벡터 그림체로 변경 금지.
개별 지정 대상은 위 파일 표에 기재한 상자 디자인과 리본 없는 화분이다.

기존 리본 화분 파일은 교체·제외한다. 이전 버전은 Git 이력에 남는다.
실제 출석 지급·진행도 저장 구현이나 UI 프론트엔드 구현은 이번 변경에 포함하지 않는다.
