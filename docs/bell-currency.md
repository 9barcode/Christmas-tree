# 벨 재화

- 게임 내 장식 판매 가치, 보유 잔액, 가격 필터, 선택 합계는 벨로 표시한다. 트리 판매 보상은 벨이 아니라 토스포인트로 지급한다.
- 1벨 = 1토스포인트. 교환 시 보유 벨 전액을 사용하며 실제 지급 내역은 포인트로 표시한다.
- 트리 판매는 별도 프로모션 코드로 한국시간 기준 하루 한 번 고정 50P를 지급한다. Toss 프로모션도 사용자별 일일 한도를 50P로 설정한다. 이 보상을 벨 잔액에 추가하지 않아 50벨과 50P가 중복 지급되지 않는다.
- 기존에 장식 판매로 쌓인 벨 잔액은 그대로 유지하며, 장식 판매 벨은 기존 `TOSS_PROMOTION_CODE_EXCHANGE`로 교환한다.
