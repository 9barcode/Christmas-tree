# 트리 꾸미기 — 최신 핵심 기획 (BM v3)
기준일: 2026-10-22. **기획 확정 사항**이며 아직 코드/서버에 구현된 상태는 아니다. 기존 [BM v2](bm-v2.md)의 장식 획득·완성·교환 규칙보다 본 문서를 우선한다.

## 핵심 흐름
**트리 꾸미기(앱 최초 진입/메인)** → 장식 공장(리워드 광고 → 랜덤 장식 1개 생산) → 보관함(트리 배치 또는 자유 판매) → 도감(서로 다른 30종을 영구 수집) → 30종 완성 시 30원 상당 보상.

## 화면과 기존 디자인
- 메인은 반드시 **기존 트리 꾸미기**. 상단 트리 슬롯, 기존 트리·화분·배경·벽난로·눈·장식 터치 배치와 사진 저장/공유 유지.
- 주 화면 이동은 **하단 탭 4개**: 트리 꾸미기 / 장식 공장 / 보관함 / 도감. 공장 생산은 별도 페이지이며 앱을 새로 만들지 않는다. 촬영/공유 시 탭 숨김.
- 트리 꾸미기 실제 화면과 사진에는 광고를 배치하지 않는다. 현재 로딩 배너 및 광고 그룹 변수는 별도 변경 요청 전까지 보존.
- 장식 30종은 기존 에셋 구성(선물 4, 미니카 1, 인형 1, 오너먼트 22, 전구줄 1, 별 1)을 우선 재사용한다. 기존 5개 트리 슬롯 해제 방식은 별도 변경 전까지 유지.

## 생산·판매·도감
- 공장에서 **리워드형 광고 1회 보상 확인 후** 장식 1개를 무작위 생산. **하루 생산 최대 10회**를 기본으로 한다. 현행 v2의 *트리별* 10회와 달리 공장 생산 한도 기준이므로 최종 서버 범위(사용자 전체/슬롯별)는 구현 전 고정할 것.
- 장식은 **1원 / 2원 / 3원**의 세 가치로 구분한다. 각 가치별 장식 종류·개별 등장 확률은 아직 확정하지 않았다(임의로 15/10/5나 균등 확률을 확정값으로 적용 금지).
- 모든 장식은 **최초 획득본까지 자유 판매** 가능하며, 판매 가치(1/2/3원)는 실제 **토스포인트 교환 가능 잔액**으로 서버에 적립한다. 판매하지 않으면 트리에 배치·재배치·회수·보관 가능. 판매 시 보유 수량만 차감.
- **최초 획득 시 도감 영구 등록**, 판매·배치·회수 이후에도 등록 유지. **서로 다른 30종 모두 등록 시 추가 30원** 상당 보상(계정당 최초 1회; 반복 지급 금지).
- 출석/결석과 기존 '트리 하나에 30개 부착하면 30원' 방식은 신규 BM에서 사용하지 않는다. 모든 장식의 보유량·도감·판매 원장과 프로모션 지급 상태는 구분해 보관한다.

## 구현 시 유의
- 공장 화면에서 광고 동의 → 실제 리워드 지급 이벤트 확인 → 서버 추첨·아이템 발급 → 결과 확인 → 배치/판매 순서로 진행한다. 광고 요청마다 단일 요청 ID, 일일 한도, 중복 이벤트 방지·재시도/복구를 적용한다.
- 장식 추첨/판매/잔액/도감 완성과 실제 지급은 **서버 권위 상태 및 중복 처리 방지**가 필수. 단말 조작으로 재추첨·중복 판매·보상 재지급이 불가해야 한다.
- 토스포인트 지급 가능 여부·광고/프로모션 정책과 실제 손익은 출시 전 확인 과제로 남긴다. 기획 문서가 플랫폼 승인을 의미하지 않는다.
- 당장은 **문서 변경만**. 기존 BM v2 구현·API·런타임 변수·서버 DB를 임의로 수정하지 않는다. 신규 BM 구현 시 명세/마이그레이션/이관/검증을 별도 진행한다.
