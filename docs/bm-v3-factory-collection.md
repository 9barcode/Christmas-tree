# 트리 꾸미기 — 최신 핵심 기획 (BM v3)
기준일: 2026-10-22. **기획 확정 사항**이며 아직 코드/서버에 구현된 상태는 아니다. 기존 [BM v2](bm-v2.md)의 장식 획득·완성·교환 규칙보다 본 문서를 우선한다.

## 핵심 흐름
**트리 꾸미기(앱 최초 진입/메인)** → 장식 공장(리워드 광고 → 랜덤 장식 1개 생산) → 보관함(트리 배치 또는 자유 판매) → 도감(서로 다른 30종을 영구 수집) → 30종 완성 시 30원 상당 보상.

## 화면과 기존 디자인
- 메인은 반드시 **기존 트리 꾸미기**. 기존 기본 트리 1개(초록색 고정), 기존 트리·화분·배경·벽난로·눈·장식 터치 배치와 사진 저장/공유 유지.
- 주 화면 이동은 **하단 탭 4개**: 트리 꾸미기 / 장식 공장 / 보관함 / 도감. 공장 생산은 별도 페이지이며 앱을 새로 만들지 않는다. 촬영/공유 시 탭 숨김.
- 트리 꾸미기 실제 화면과 사진에는 광고를 배치하지 않는다. 현재 로딩 배너 및 광고 그룹 변수는 별도 변경 요청 전까지 보존.
- 장식 30종은 기존 에셋 구성(선물 4, 미니카 1, 인형 1, 오너먼트 22, 전구줄 1, 별 1)을 우선 재사용한다. **트리 추가 슬롯(2~5번), 슬롯 잠금·해제, 추가 트리 생성·선택 기능은 전면 폐지**한다. 최초 기본 트리 1개만 사용하며 슬롯 선택 UI도 표시하지 않는다. 기존 다중 트리 관련 데이터는 이관 정책 확정 전 임의 삭제하지 않는다.

## 생산·판매·도감
- 공장에서 **리워드형 광고 1회 보상 확인 후** 장식 1개를 무작위 생산. **하루 생산 최대 10회**를 기본으로 한다. 현행 v2의 *트리별* 10회와 달리 **사용자 계정 전체 하루 10회**로 통합하며 트리/슬롯별 한도는 사용하지 않는다.
- 장식은 **1원 / 2원 / 3원**의 세 가치로 구분한다. 각 가치별 장식 종류·개별 등장 확률은 아직 확정하지 않았다(임의로 15/10/5나 균등 확률을 확정값으로 적용 금지).
- 모든 장식은 **최초 획득본까지 자유 판매** 가능하며, 판매 가치(1/2/3원)는 실제 **토스포인트 교환 가능 잔액**으로 서버에 적립한다. 판매하지 않으면 트리에 배치·재배치·회수·보관 가능. 판매 시 보유 수량만 차감.
- **최초 획득 시 도감 영구 등록**, 판매·배치·회수 이후에도 등록 유지. **서로 다른 30종 모두 등록 시 추가 30원** 상당 보상(계정당 최초 1회; 반복 지급 금지).
- 출석/결석과 기존 '트리 하나에 30개 부착하면 30원' 방식은 신규 BM에서 사용하지 않는다. 모든 장식의 보유량·도감·판매 원장과 프로모션 지급 상태는 구분해 보관한다.

## 구현 시 유의
- 공장 화면에서 광고 동의 → 실제 리워드 지급 이벤트 확인 → 서버 추첨·아이템 발급 → 결과 확인 → 배치/판매 순서로 진행한다. 광고 요청마다 단일 요청 ID, 일일 한도, 중복 이벤트 방지·재시도/복구를 적용한다.
- 장식 추첨/판매/잔액/도감 완성과 실제 지급은 **서버 권위 상태 및 중복 처리 방지**가 필수. 단말 조작으로 재추첨·중복 판매·보상 재지급이 불가해야 한다.
- 토스포인트 지급 가능 여부·광고/프로모션 정책과 실제 손익은 출시 전 확인 과제로 남긴다. 기획 문서가 플랫폼 승인을 의미하지 않는다.
- 당장은 **문서 변경만**. 기존 BM v2 구현·API·런타임 변수·서버 DB를 임의로 수정하지 않는다. 신규 BM 구현 시 명세/마이그레이션/이관/검증을 별도 진행한다.


## 공장 야근 시스템 — 2026-10-22 추가 확정
- 기본 생산: 한국시간 매일 10회. 생산은 리워드 광고 1회당 랜덤 장식 1개이며 기존 광고 성공 검증과 서버 중복 방지를 유지한다.
- **기본 생산 10회 소진 후** '야근수당 주고 공장 재가동!' 버튼을 노출한다. 명시적으로 선택하고 별도 리워드 광고 보상을 정상 획득한 경우에만 **추가 생산 10회**를 해제한다.
- **야근 리셋은 계정당 한국시간 하루 1회만 가능**, 이월/중복/재시도 중복 적용 금지. 하루 최대 생산 20회이며 광고는 생산 20회 + 야근 해제 1회까지 가능하다.
- 초기화는 한국시간 자정. 기본/추가 사용 횟수, 야근 해제 여부는 서버가 관리한다. 야근 광고 실패 시 해제하지 않고 재시도 가능.
- 리셋은 **새로운 생산 기회 10회 제공**이며 이미 생산·판매·배치·도감 등록한 장식이나 잔액을 초기화하지 않는다.
- 공장 야근 UI 문구: 제목 '오늘 공장 문 닫았습니다!', 설명 '산타에게 야근수당을 지급하고 공장을 다시 돌려볼까요?', 버튼 '야근수당 주고 공장 재가동!', 보조문구 '광고 시청 후 추가 생산 10회 · 오늘 1번'.
- 공장·보관함·도감은 기존 앱의 크림색·따뜻한 초록/버건디·붓터치 질감을 유지하는 **각각의 독립 페이지**로 구성한다. 트리 꾸미기는 계속 첫 진입 메인이다.

## 장식 공장 애니메이션 핵심 기획 (2026-10-22)
- **디자인:** 기존 트리 메인과 동일한 크림·우드·초록 계열, 부드러운 붓터치 크리스마스 분위기 유지. 공장은 독립 페이지.
- **대기:** 컨베이어 벨트가 느리게 순환하고, 산타는 작업지시서 확인·끄덕임 등 작은 반복 동작. 과한 화면 이동이나 상시 화려한 효과 금지.
- **생산 성공:** 리워드 광고 보상 확인 후 벨트 가속 → 선물 상자 이동·정지 → 상자 개봉 → 랜덤 장식(1·2·3원) 공개. 결과에서 **보관/트리 배치/판매** 선택. 결과 연출은 2~3초 내외 목표, 건너뛰기 가능.
- **기본 10회 소진:** 벨트 정지, 조명 살짝 어두워짐, 산타 하품/지친 표정. ‘오늘 공장 문 닫았습니다!’ 및 ‘야근수당 주고 공장 재가동!’ 표시.
- **야근 광고 성공:** 조명 점등·산타 기운 회복·벨트 재가동, ‘추가 생산 10회 시작!’ 안내. 광고 실패 시 재가동 연출·횟수 지급 없음.
- **구현 우선순위:** ① 벨트/상자/결과 ② 산타 idle·생산 모션 ③ 야근 표정·조명. 화면 이탈·모션 감소 설정에서 반복 애니메이션을 중단하고, 애니메이션이 실제 서버 보상 지급 시점을 결정하지 않도록 분리한다.
