# 포도키우기 프론트엔드 참고 내역

확인일: 2026-10-16
원본: https://github.com/bluehawhy/PodoMoa

## 확인한 소스
- `src/main.tsx`: 준비 상태, 첫 이용안내, 광고 및 저장 잠금, 앱 복귀/60초 상태 갱신, 지급 결과 복구.
- `src/features/attendance/PlayGuide.tsx`, `AttendanceCalendar.tsx`, `PreviousRewards.tsx`, `PromotionRewards.tsx`: 안내 카드·30칸 도장표·이전 보상·미션 지급 상태.
- `src/features/game/claim.ts`, `missions.ts`: 서버 지급 상태 조회와 재시도.

## 트리꾸미기에 적용
- 홈 준비 완료 후 첫 이용안내 표시, 닫으면 기기에 확인 기록 저장. 미리보기에는 자동 표시하지 않는다.
- 이용안내에 바닥/가지 터치 배치와 별·전구 줄 고정 설명 추가.
- 광고 처리 중 버튼·슬롯 입력 잠금과 처리 문구, 완료/당일 출석 중복 요청 사전 차단.
- 한국 날짜가 바뀌었을 때 앱 복귀 및 60초 간격으로 출석 버튼 갱신. 광고/배치 중에는 갱신 보류.
- 기존 루돌프 도장표와 트리별 진행도를 유지.

## 서버 연동 시 참조
포도키우기는 출석·미션·이전 보상을 서버에서 받아 지급 요청의 결과를 복구한다. 트리꾸미기는 현재 로컬 프론트엔드 단계다. 서버 API·광고 검증·지급 결과가 없으므로 실제 금액이나 지급 완료를 임의로 표시하지 않는다. 추후 초기 상태 조회는 로딩 준비 작업에 포함하고 지급 중/실패/확정 상태를 별도로 처리해야 한다.

트리의 첫 출석으로 다음 슬롯을 여는 규칙, 완성한 트리 보존, 사용자가 고른 장식 위치는 트리 기획을 우선한다. 포도키우기의 수확 후 화분 초기화 동작은 복사하지 않는다.
